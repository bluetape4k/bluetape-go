# testcontainers/falkordb

`testcontainers/falkordb` starts the immutable
`falkordb/falkordb:latest@sha256:adbddd418916c25618564ff8597a919b08bc76452ebeb74eb985c38d7281df62`
image, waits for Redis port readiness, and registers bounded termination.
`AddressKey` exposes the caller-owned Redis address.
