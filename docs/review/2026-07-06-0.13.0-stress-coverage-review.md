## 잔여 위험

This PR intentionally avoids adding stress tests to external-resource packages
without a concrete owned concurrency contract. If later review finds a
container lifecycle race or SQL driver goroutine ownership bug, that should be
tracked as a package-local issue with serial Testcontainers validation.
