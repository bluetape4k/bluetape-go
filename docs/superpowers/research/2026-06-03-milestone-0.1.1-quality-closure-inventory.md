## 코드 범위

0.1.1 review 대상은 0.1.0 foundation surface로 제한한다.

- `core`: pointer, zero/default, string, number, validation helpers
- `collections`: chunk, distinct, grouping, error-aware map/filter helpers
- `concurrency`: errgroup wrapper, parallel map/foreach, worker pool, panic capture
- `codec`: Base58, Base62/URL62, Base64, Hex helpers
- `serialization`: JSON, bytes, string, versioned envelope
- `compression`: gzip, zlib, deflate, zstd, lz4, snappy byte and stream APIs
- `leader`: leader election SPI and Redis-backed elector
- `testcontainers`: Redis, PostgreSQL, MySQL, Kafka, NATS test fixtures
- `testing`: Eventually/Consistently and concurrency testers

`resilience`는 0.2.0 scope이므로 0.1.1 retrospective review에서 제외한다.
