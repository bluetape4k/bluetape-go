# 0.4.0 Runnable Examples

Issue #137 is an example gate over the 0.4.0 API surface, not a new API
implementation issue.

The useful closure pattern is:

- add package-local `Example*` tests while implementing each package;
- keep examples deterministic and service-free so ordinary `go test` runs them;
- link package READMEs to the compile-checked example files instead of copying
  long snippets into every README.

For future milestones, close the runnable-example gate after package READMEs
exist and before diagram work, so diagrams can reference stable onboarding
examples.
