# 0.4.0 Runnable Examples

Issue #137은 0.4.0 API surface에 대한 example gate이지 새 API implementation
issue가 아니다.

유용한 closure pattern은 다음과 같다.

- 각 package를 구현할 때 package-local `Example*` test를 함께 추가한다.
- 일반 `go test`가 실행할 수 있도록 example은 deterministic하고 service-free하게
  유지한다.
- 긴 snippet을 모든 README에 복사하지 말고 package README에서 compile-checked
  example file로 link한다.

향후 milestone에서는 package README가 생긴 뒤, diagram work 전에 runnable-example
gate를 닫는다. 그래야 diagram이 stable onboarding example을 참조할 수 있다.
