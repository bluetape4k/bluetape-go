# 0.4.0 Stress Cancellation Gate

Issue #136은 milestone gate이지 새 helper package가 아니다.

유용한 closure pattern은 다음과 같다.

- package-local stress/cancellation test는 owning issue 안에서 구현한다.
- dependent package가 merge된 뒤에는 각 acceptance criterion을 concrete test와 race
  command에 mapping하는 milestone gate matrix를 추가한다.
- issue가 acceptance criteria로 명시하지 않은 heavy soak test와 benchmark loop는
  release gate 밖에 둔다.

향후 milestone에서는 gate issue를 일찍 만들고 child issue body에서 참조한다. 모든
dependent package가 `develop`에 merge된 뒤에만 gate를 닫는다.
