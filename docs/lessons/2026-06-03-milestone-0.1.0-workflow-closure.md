# Lesson: 0.1.0 Workflow Closure

## What happened

Milestone 0.1.0은 foundation code와 PR merge를 완료했지만 workflow evidence가
부족했다. 주요 누락은 다음과 같다.

- design/spec/plan artifact가 `docs/superpowers` 아래에 일관되게 기록되지 않았다.
- 완료 전 Step 6-R code review evidence가 남지 않았다.
- issue/PR 생성 시점에 `milestone`과 `assignee` metadata gate가 강제되지 않았다.

## What resolved it

0.1.1을 retrospective quality closure milestone로 만들었다. 이 작업에서
research/spec/plan/review artifact를 보강하고, 0.1.0 foundation surface에 7-tier
review를 실행했으며, review 중 발견된 P1 JSON trailing-data finding을 수정했다.

## Rule for next time

모든 milestone issue/PR은 다음 순서를 지킨다.

1. issue/PR 생성 전에 milestone을 만들거나 확인한다.
2. issue/PR을 즉시 `debop`에게 assign한다.
3. milestone을 즉시 설정한다.
4. 생성 직후 metadata gate를 실행한다.

```bash
gh issue view <number> --json milestone,assignees
gh pr view <number> --json milestone,assignees
```

둘 중 하나라도 비어 있으면 workflow를 멈추고 metadata를 수정한 뒤 implementation
또는 merge gate로 진행한다.
