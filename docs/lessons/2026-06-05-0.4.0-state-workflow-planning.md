# 0.4.0 State And Workflow Planning Lessons

Issue: #135
Milestone: 0.4.0

## Lesson

새 Go milestone은 Kotlin module evidence를 그대로 옮기지 말고, implementation 전에
작은 Go-first package split으로 바꿔야 한다. 0.4.0에서는 `state`, `workreport`,
`workflow`가 유용한 split이고 Kotlin DSL, coroutine, reactive, Virtual Thread layer는
out of scope로 둔다.

## Applied Guardrails

- `state`는 finite state machine work가 먼저 land할 수 있도록 independent하게 둔다.
- `workreport`는 runner가 consume하기 전에 status와 failure policy를 소유한다.
- `workflow`는 일반 `context.Context`-driven work function을 compose한다.
- stress/cancellation coverage와 compile-checked example은 optional cleanup이 아니라
  milestone issue로 추적한다.
- package README와 diagram은 API stabilization 뒤에 따라온다.
