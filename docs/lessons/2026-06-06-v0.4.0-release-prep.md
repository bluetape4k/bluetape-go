# v0.4.0 Release Prep

## Context

Milestone `0.4.0`은 open issue 0개로 closed 상태였지만, tag 전에 release-specific
hygiene이 더 필요했다.

- `CHANGELOG.md`는 0.4.0 entry를 `Unreleased` 아래에 두고 있었다.
- `v0.4.0` local/remote tag가 없었다.
- GitHub Release `v0.4.0`이 없었다.
- `WIP.md`는 다음 0.5.0 planning queue가 아니라 0.4.0 release preparation 상태를
  설명하고 있었다.

## Decision

release PR 전에 0.4.0 changelog entry를 `## [v0.4.0] - 2026-06-06`으로 승격하고,
remaining release checklist는 명시적으로 유지한 채 `WIP.md`를 0.5.0 planning queue로
이동한다.

## Validation

- Milestone `0.4.0`: closed, 0 open issues.
- Open PR list: release preparation 전 empty.
- Tag/release check: `v0.4.0` tag와 GitHub Release 없음.
- Changelog gate: tag 전에 release section 추가.

## Forward Rule

Go release에서는 tag target에 matching `CHANGELOG.md` version section이 포함되기
전까지 tag를 만들거나 push하지 않는다.
