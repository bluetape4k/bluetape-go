# v0.4.0 Release Prep

## Context

Milestone `0.4.0` is closed with zero open issues, but the repository still
needed release-specific hygiene before tagging:

- `CHANGELOG.md` kept the 0.4.0 entries under `Unreleased`.
- `v0.4.0` did not exist as a local or remote tag.
- GitHub Release `v0.4.0` did not exist.
- `WIP.md` still described the repository as being in 0.4.0 release
  preparation rather than the next 0.5.0 planning queue.

## Decision

Promote the 0.4.0 changelog entries into `## [v0.4.0] - 2026-06-06` before the
release PR, and move `WIP.md` to the 0.5.0 planning queue while keeping the
remaining release checklist explicit.

## Validation

- Milestone `0.4.0`: closed, 0 open issues.
- Open PR list: empty before release preparation.
- Tag and release checks: no `v0.4.0` tag or GitHub Release existed.
- Changelog gate: release section added before tagging.

## Forward Rule

For Go releases, do not create or push a tag until the tag target contains the
matching `CHANGELOG.md` version section.
