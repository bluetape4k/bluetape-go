# Issue #548 Geo Coordinate와 Geohash lesson

## 결정

첫 좌표 slice는 외부 dependency나 storage/index 계층 없이 `geo`의 값과 순수
계산만 제공한다. `Point`와 `Bounds`는 private field와 유효한 zero value를
가지며, `Cell`은 accessor가 안전하지만 `Validate` 전에는 성공한 decode 결과로
취급하지 않는다. Geohash는 precision 1..12의 canonical lowercase만 허용한다.

`Bounds`는 `east < west`를 antimeridian crossing으로 해석하고, 포함 판정에서는
`-180`과 `180`을 같은 meridian으로 취급한다. 거리는 평균 지구 반지름
`6,371,008.8m`를 쓰는 Haversine 구면 근사이며 측량, 과금, 법적 경계 판단을
보증하지 않는다.

## 구현과 검증에서 확인한 hardening

- public constructor는 non-finite와 범위 오류를 field 순서로 거부하고 zero
  result와 `%w` sentinel을 반환한다.
- decode는 길이를 먼저 제한한 뒤 표준 alphabet만 읽어 oversized input과 alias를
  fail-closed로 처리한다.
- pole, antipode, antimeridian, midpoint와 WGS 84 모서리를 table test로 고정하고
  fuzz에서 성공한 cell의 center/bounds invariant를 반복 검증한다.
- benchmark는 correctness fixture를 timer 전에 만들고 SHA, dirty state, Go/OS,
  fixture 순서, metric 방향과 raw 3회 결과를 tracked WIP에 남긴다.
- `Benchmarked SHA`와 review HEAD는 구분한다. benchmark 뒤 실행문이 바뀌면
  재측정하고, evidence/문서-only commit만 뒤따르면 그 사실을 명시한다.

## 작업 방식에서 얻은 교훈

- 한국어 Go doc도 lexical lint 계약을 따른다. `// Point는 ...`처럼 조사를
  identifier에 붙이면 `revive`가 거부하므로 `// Point 값은 ...`처럼 exact
  identifier 뒤 ASCII 공백을 둔다. 이 규칙은 chezmoi source의
  `$bluetape-go-patterns`에 RED/GREEN pressure test와 함께 반영했다.
- 계획의 test snippet도 그대로 신뢰하지 않는다. 이번 계획에는
  `distance_test.go`의 사용하지 않는 `strings` import와 `geohash_test.go`의 누락된
  `strings` import가 각각 있었다. RED가 의도한 undefined symbol 때문에
  실패하는지 compiler output을 읽고 import noise를 먼저 제거해야 한다.
- green Testcontainers 실행 뒤에도 Docker runtime은 사라질 수 있다. 현재 gate는
  현재 `colima status`, context, `docker info`와 최종 command exit code로 증명하며
  이전 성공을 재사용하지 않는다. 불일치 상태에서는 healthy VM을 재시작하지 말고
  실제 socket/instance failure를 확인한 뒤 기존 VM만 복구한다.

## 다음 변경자를 위한 지침

- 좌표 normalization, projection, polygon, neighbor/radius cover, spatial index를
  이 작은 package에 암묵적으로 추가하지 않는다. 별도 use case/spec로 분리한다.
- longitude `-180`/`180`, midpoint upper-half 선택과 inclusive bounds를 바꿀 때는
  known vector, 모서리 round trip과 fuzz invariant를 함께 갱신한다.
- nanosecond 값을 고정 release gate로 사용하지 않는다. allocation threshold와
  correctness를 gate로 두고 환경별 `ns/op`은 관찰값으로 남긴다.
- public declaration 하나를 추가한 직후 configured linter를 실행해 한국어 Go doc
  형식 오류가 package 전체로 확산되지 않게 한다.

## 확인된 범위

`geo` unit/race/example, 두 10초 fuzz target, benchmark 3회, statement coverage
97.9%, formatter, tidy, vet, lint, 전체 normal/race Testcontainers suite와 canonical
`make ci`가 통과했다. PR/remote CI, merge, tag, publication과 downstream adoption은
이 lesson의 범위 밖이다.
