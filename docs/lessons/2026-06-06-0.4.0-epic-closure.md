# 0.4.0 Epic Closure

Issue #4는 0.4.0 state/workflow milestone의 final closure gate다.

유용한 closure pattern은 다음과 같다.

- WIP를 갱신하기 전에 milestone의 모든 child issue가 closed인지 확인한다.
- epic을 닫기 전에 WIP를 "remaining issue count"에서 "milestone closure"로 바꾼다.
- 실제 tag/release PR 전까지 CHANGELOG entry는 `Unreleased` 아래에 둔다.
- cleanup PR이 merge되고 CI가 통과한 뒤에만 epic과 milestone을 닫는다.

향후 milestone에서는 follow-up gate issue를 추가할 때 epic body checklist를 함께
동기화한다. GitHub issue state가 closure의 source of truth이고, WIP는 repo-local
release queue를 기록한다.
