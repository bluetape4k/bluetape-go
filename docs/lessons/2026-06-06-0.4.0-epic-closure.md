# 0.4.0 Epic Closure

Issue #4 is the final closure gate for the 0.4.0 state/workflow milestone.

The useful closure pattern is:

- verify every child issue in the milestone is closed before updating WIP;
- update WIP from "remaining issue count" to "milestone closure" before closing
  the epic;
- keep CHANGELOG entries under `Unreleased` until the actual tag/release PR;
- close the epic and milestone only after the cleanup PR merges and CI passes.

For future milestones, keep the epic body checklist synchronized when adding
follow-up gate issues. GitHub issue state is the source of truth for closure,
while WIP records the repo-local release queue.
