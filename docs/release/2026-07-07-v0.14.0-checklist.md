## 릴리스 단계

1. Commit 0.14.0 release prep on this branch.
2. Open PR to `main`.
3. Wait for GitHub CI and merge state.
4. Merge the release PR.
5. Fast-forward local `main` to `origin/main`.
6. Confirm `CHANGELOG.md` on `main` contains `v0.14.0`.
7. Create annotated tag `v0.14.0` on `main`.
8. Push the tag.
9. Create GitHub Release `v0.14.0` from the changelog section with validation
   evidence and tag target commit.
10. Verify tag, release metadata, local status, and open PR state.

## 롤백 메모

- Before tag push: close the PR and delete `release/v0.14.0-main-promotion`.
- After tag push but before GitHub Release: delete the local/remote tag only if
  explicitly approved with the tag object and commit named.
- After GitHub Release: do not retag by default; publish a corrective release
  note or patch version unless explicit retag approval is given.
