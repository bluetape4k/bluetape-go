정리하고 Echo adapter의 post-`v0.20.0` 후속 수정을 배포한다.

## 롤백과 재실행

- Remote tag push 전에는 승인된 PR/branch만 닫거나 되돌리고, tag는 만들지
  않습니다.
- Remote tag push 뒤에는 tag를 이동하거나 다시 사용하지 않습니다. 결함은
  corrective patch release로 처리합니다.
- GitHub Release publication만 실패하면 verified remote tag를 기준으로 같은
  body를 다시 게시하고 live body를 읽습니다.
- Nightly 또는 CI가 실패하면 동일 exact head에서 원인을 진단하고, head가
  바뀌면 이전 성공 증거를 폐기합니다.
