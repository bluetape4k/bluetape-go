## Release Steps

1. Commit 0.16.0 release prep on `release/v0.16.0-prep`.
2. Open PR to `develop` and wait for CI.
3. Merge the release-prep PR.
4. Close GitHub milestone `0.16.0` after the changelog gate exists on
   `develop`.
5. Open the release promotion PR to `main`; if direct promotion is conflicting,
   use the protected-branch projection fallback from `origin/main`.
6. Wait for GitHub CI and merge state.
7. Merge the release PR.
8. Fast-forward local `main` to `origin/main`.
9. Confirm `CHANGELOG.md` on `main` contains `v0.16.0`.
10. Create annotated tag `v0.16.0` on `main`.
11. Push the tag.
12. Create GitHub Release `v0.16.0` from the changelog section with validation
    evidence and tag target commit.
13. Verify tag, release metadata, local status, and open PR state.

## Rollback Notes

- Before tag push: close the release PR and delete the temporary release branch.
- After tag push but before GitHub Release: delete the local/remote tag only if
  explicitly approved with the tag object and commit named.
- After GitHub Release: do not retag by default; publish a corrective patch
  release note unless explicit retag approval is given.
