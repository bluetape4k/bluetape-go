## bluetape4k 근거

- `bluetape4k-graph`: graph abstraction, backend, graph I/O, domain example.
- `bluetape4k-text`: tokenizer-core, Korean/Japanese tokenizer, text search, language detection.
- `bluetape4k-image`: image processing 및 benchmark module.
- `bluetape4k-javers`: audit, aggregate, event, history concept.
- `bluetape4k-aws`: S3, SQS, DynamoDB, Ktor/Spring example, SDK helper pattern.
- `bluetape4k-projects/io/*`: HTTP, gRPC, CSV, protobuf, Avro, Tink, JSON, codec helper.
- `bluetape4k-projects/io/tink`: AEAD/DAEAD, associated data, versioned keyset, Redis keyset store, MAC,
  digest, rotation guidance.
