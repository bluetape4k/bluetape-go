# 0.1.0 Foundation Research

## Milestone

0.1.0 - foundation package: core support, collections, goroutine helper, codec/compression, Redis leader election,
shared test infrastructure.

## bluetape4k 근거

- `bluetape4k-projects/bluetape4k/core`: support helper, collection helper, Base58, Base62, URL62, Base64,
  Hex encoder 같은 codec.
- `bluetape4k-projects/io/io`: binary serializer 및 compressor abstraction. gzip, zstd, lz4, snappy, deflate,
  bzip2, zip, streaming compressor variant를 포함한다.
- `bluetape4k-projects/testing/testcontainers`: 재사용 가능한 integration-test fixture pattern.
- `bluetape4k-leader`: leader election core와 Redis, etcd, Kubernetes, Consul, Hazelcast, MongoDB, DynamoDB,
  Zookeeper backend.

## Go 방향

작고 framework-free인 package부터 시작한다.

- `core`: validation, support, pointer/value helper, codec.
- `collections`: Go stdlib가 부족한 경우에만 generic slice/map helper.
- `concurrency`: context-aware goroutine helper, errgroup-style composition, bounded parallelism, panic-to-error capture.
- `serialization`: 안전한 binary serializer interface와 compression wrapper.
- `testcontainers`: Redis, PostgreSQL, messaging service 전반에 공유되는 fixture convention.
- `leader`: 기존 Redis implementation을 harden하고 compatibility rule을 정의한다.

## Dependency Candidates

- `golang.org/x/sync`: errgroup, semaphore, singleflight primitive.
- `github.com/klauspost/compress`: actively maintained compression package.
- `github.com/pierrec/lz4`: LZ4 support.
- `github.com/redis/go-redis/v9`: Redis backend client.
- `github.com/testcontainers/testcontainers-go`: integration fixture runtime.
