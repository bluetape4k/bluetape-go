# 0.5.0 Batch Research

## Milestone

0.5.0 - checkpoint와 example을 가진 batch processing.

## bluetape4k 근거

- `bluetape4k-projects/docs/superpowers/plans/2026-04-10-utils-batch-plan.md`는 reader/processor/writer,
  chunk loop, retry/skip policy, restart, checkpointing, workflow integration, example을 설명한다.
- `bluetape4k-exposed/utils/batch`: batch core 및 benchmark hub.
- `bluetape4k-leader/examples/batch-scheduler`: leader-guarded batch scheduling.

## Go 방향

- `batch`: generic reader, processor, writer, job, step, chunk loop.
- retry 및 skip policy는 가능하면 `resilience` package를 재사용한다.
- checkpoint store는 interface-first로 두고, database adapter 전에 memory 및 file adapter를 둔다.
- example은 scheduler 및 migration workload에서 batch와 leader election을 연결해야 한다.

## Dependency Candidates

- core loop는 local implementation을 우선한다.
- 0.2.0 이후에는 retry에 `resilience` package를 재사용한다.
- future store는 example 필요에 따라 Redis, PostgreSQL, S3를 사용할 수 있다.
