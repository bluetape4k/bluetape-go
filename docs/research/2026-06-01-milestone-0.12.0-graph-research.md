# 0.11.0 Graph Research

## Milestone

0.11.0 - graph package와 example.

## bluetape4k 근거

- `bluetape4k-graph`는 shared graph abstraction, graph backend module, graph I/O, benchmark, example을 제공한다.
- example에는 code graph, fraud detection, recommendation, knowledge graph, observability incident, Ktor integration이 있다.
- backend에는 Neo4j, Memgraph, AGE, TinkerPop, FalkorDB 영역이 있다.

## Go 방향

- broad backend abstraction 전에 graph I/O와 domain example부터 시작한다.
- backend adapter는 얇게 유지하고 backend-specific capability를 숨기지 않는다.
- shared behavior에는 conformance test를 우선한다.
- Cypher, Gremlin, backend query language를 leaky generic query API 뒤에 숨기지 않는다.

## Dependency Candidates

- `github.com/neo4j/neo4j-go-driver/v5`: Neo4j Bolt driver.
- Memgraph, AGE, TinkerPop, FalkorDB의 backend driver maturity는 implementation 전에 research해야 한다.
