# 0.12.0 Graph Research

## Milestone

0.12.0 - Graph packages and examples.

## bluetape4k Evidence

- `bluetape4k-graph` offers a shared graph abstraction, graph backend modules,
  graph I/O, benchmarks, and examples.
- Examples include code graphs, fraud detection, recommendations, knowledge
  graphs, observability incidents, and Ktor integration.
- Backends include Neo4j, Memgraph, AGE, TinkerPop, and FalkorDB areas.

## Go Direction

- Start with graph I/O and domain examples before broad backend abstraction.
- Keep backend adapters thin and honest about backend-specific capabilities.
- Prefer conformance tests for shared behavior.
- Avoid hiding Cypher, Gremlin, or backend query languages behind a leaky
  generic query API.

## Dependency Candidates

- `github.com/neo4j/neo4j-go-driver/v5`: Neo4j Bolt driver.
- Backend driver maturity for Memgraph, AGE, TinkerPop, and FalkorDB must be
  researched before implementation.
