# 0.10.0 Audit And JaVers Pattern Research

## Milestone

0.10.0 - Audit and event packages inspired by bluetape4k-javers without
depending on JaVers.

## bluetape4k Evidence

- `bluetape4k-javers`: aggregate root marker, domain event contract,
  repository/history workflows, and optional event publisher integrations.
- Examples show audit-oriented DDD and Exposed integration.

## Go Direction

- Port concepts, not the JaVers implementation.
- Define aggregate ID, aggregate root, domain event, revision, audit entry, and
  history query model.
- Start storage-neutral with in-memory conformance tests.
- Add outbox/event publisher adapters only after the core model is stable.

## Dependency Candidates

- Prefer local model and interfaces.
- Future adapters may use PostgreSQL, Redis Streams, Kafka, NATS, or DynamoDB
  based on 0.10.0 research outcomes.
