# 0.10.0 Audit And JaVers Pattern Research

## Milestone

0.10.0 - JaVers에 의존하지 않지만 `bluetape4k-javers`에서 영감을 받은 audit 및 event package.

## bluetape4k 근거

- `bluetape4k-javers`: aggregate root marker, domain event contract, repository/history workflow,
  optional event publisher integration.
- example은 audit-oriented DDD와 Exposed integration을 보여 준다.

## Go 방향

- JaVers implementation이 아니라 개념을 port한다.
- aggregate ID, aggregate root, domain event, revision, audit entry, history query model을 정의한다.
- in-memory conformance test를 가진 storage-neutral core로 시작한다.
- core model이 안정된 뒤에만 outbox/event publisher adapter를 추가한다.

## Dependency Candidates

- local model과 interface를 우선한다.
- future adapter는 0.10.0 research outcome에 따라 PostgreSQL, Redis Streams, Kafka, NATS, DynamoDB를 사용할 수 있다.
