# 0.6.0 Utilities Research

## Milestone

0.6.0 - Portable utility packages: ID generation, JWT, money, probabilistic
structures, and rule engine.

## bluetape4k Evidence

- `utils/idgenerators`: ID generator interfaces, benchmark docs, and examples.
- `utils/jwt`: JWT codec/helper concepts.
- `utils/money`: money and decimal helper concepts.
- `utils/probabilistic`: probabilistic data structures.
- `utils/rule-engine`: rule evaluation primitives.
- `utils/measured`: measured value types such as binary size.

## Go Direction

- `id`: ULID/KSUID/Snowflake-style generator package with clear ordering and
  collision guarantees.
- `jwt`: small helper layer around a maintained JWT dependency, without hiding
  security-sensitive defaults.
- `measure`: binary size parsing/formatting and related unit helpers.
- `money`: research-first, because decimal dependency and currency semantics
  matter.
- `probabilistic`: Bloom filter first if a dependency is acceptable.
- `rules`: research-first; use dependency adoption if an existing Go rules
  library is clearly better.

and can maintain stable semantics. Do not create a catch-all misc package.
