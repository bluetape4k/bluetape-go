# 0.6.0 Utilities Research

## Milestone

0.6.0 - portable utility package: ID generation, JWT, money, probabilistic structure, rule engine.

## bluetape4k 근거

- `utils/idgenerators`: ID generator interface, benchmark doc, example.
- `utils/jwt`: JWT codec/helper concept.
- `utils/money`: money 및 decimal helper concept.
- `utils/probabilistic`: probabilistic data structure.
- `utils/rule-engine`: rule evaluation primitive.
- `utils/measured`: binary size 같은 measured value type.

## Go 방향

- `id`: 명확한 ordering 및 collision guarantee를 가진 ULID/KSUID/Snowflake-style generator package.
- `jwt`: security-sensitive default를 숨기지 않는 maintained JWT dependency 주변의 작은 helper layer.
- `measure`: binary size parsing/formatting 및 관련 unit helper.
- `money`: decimal dependency와 currency semantics가 중요하므로 research-first.
- `probabilistic`: dependency가 적합하면 Bloom filter부터.
- `rules`: research-first. 기존 Go rules library가 명확히 더 낫다면 dependency adoption을 사용한다.
