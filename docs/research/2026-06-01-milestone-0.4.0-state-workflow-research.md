# 0.4.0 State And Workflow Research

## Milestone

0.4.0 - state machine 및 lightweight workflow primitive.

## bluetape4k 근거

- `bluetape4k-projects/utils/states`: state-machine concept.
- `bluetape4k-projects/utils/workflow`: sequential, parallel, conditional workflow primitive와 work report.
- batch 및 leader example은 leadership 또는 scheduled execution으로 guard되는 workflow를 보여 준다.

## Go 방향

- `state`: state, event, guard, transition error를 가진 finite state machine.
- `workflow`: `context.Context`를 사용하는 sequential, parallel, conditional runner.
- `workreport`: workflow와 batch가 공유하는 result tree.
- failure policy는 stop, continue, skip, retry, aggregate 중 명시적이어야 한다.

## Dependency Candidates

- local implementation을 우선한다. target API가 작으므로 heavy workflow engine dependency를 피한다.
- parallel workflow semantics가 맞는 곳에는 `golang.org/x/sync/errgroup`을 사용한다.
