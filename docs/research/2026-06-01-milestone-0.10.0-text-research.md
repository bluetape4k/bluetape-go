# 0.9.0 Text Research

## Milestone

0.9.0 - text search 및 tokenizer package.

## bluetape4k 근거

- `bluetape4k-text/text-search`: search functionality.
- `bluetape4k-text/tokenizer-core`: tokenizer abstraction과 blockword request/response 개념.
- `bluetape4k-text/tokenizer-korean` 및 `tokenizer-japanese`: language-specific tokenization.
- `bluetape4k-text/lingua`: language detection integration.

## Go 방향

- multi-pattern search와 blockword masking을 먼저 구현한다.
- language-specific dependency를 고르기 전에 tokenizer interface를 설계한다.
- Korean/Japanese tokenization은 dictionary, model, license, binary-size tradeoff가 중요하므로 research-heavy로 다룬다.
- language detection은 작은 Go-native option이 충분하다는 증거가 나오기 전까지 dependency-first로 둔다.

## Dependency Candidates

- Aho-Corasick 및 language detection package candidate는 #55에서 dedicated dependency review가 필요하다.
- boundary handling에는 가능한 한 standard library Unicode support를 사용한다.
