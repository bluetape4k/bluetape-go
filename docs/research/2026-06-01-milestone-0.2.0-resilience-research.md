# 0.2.0 Resilience Research

## Milestone

0.2.0 - Resilience policies inspired by bluetape4k-resilience4j.

## bluetape4k Evidence

- `bluetape4k-projects/infra/resilience4j`: coroutine-friendly resilience
  integration.
- `bluetape4k-projects/ktor/resilience4j`: Ktor policies and status-page
  integration.
- Workshop examples include Spring Boot resilience4j coroutine examples and
  cache-resilience examples.

## Go Direction

Port the service-level concepts, not the JVM library shape:

- Retry with backoff, jitter, retryable predicates, and context cancellation.
- Timeout wrappers that compose with `context.Context`.
- Circuit breaker with deterministic half-open behavior.
- Bulkhead/concurrency limiter.
- HTTP client/server middleware for `net/http`.
- Structured event hooks for metrics or OpenTelemetry integration.

## Dependency Candidates

- `github.com/cenkalti/backoff/v4`: exponential backoff.
- `github.com/sony/gobreaker`: circuit breaker.
- `golang.org/x/sync/semaphore`: bulkhead implementation candidate.
