# 0.2.0 Resilience Research

## Milestone

0.2.0 - `bluetape4k-resilience4j`에서 영감을 받은 resilience policy.

## bluetape4k 근거

- `bluetape4k-projects/infra/resilience4j`: coroutine-friendly resilience integration.
- `bluetape4k-projects/ktor/resilience4j`: Ktor policy와 status-page integration.
- workshop example에는 Spring Boot resilience4j coroutine example과 cache-resilience example이 있다.

## Go 방향

JVM library 모양이 아니라 service-level 개념을 port한다.

- backoff, jitter, retryable predicate, context cancellation을 가진 retry.
- `context.Context`와 조합되는 timeout wrapper.
- deterministic half-open behavior를 가진 circuit breaker.
- bulkhead/concurrency limiter.
- `net/http`용 HTTP client/server middleware.
- metrics 또는 OpenTelemetry integration을 위한 structured event hook.

## Reference Inputs

- `failsafe-go`: composable policy shape.
- `github.com/cenkalti/backoff`: exponential backoff 및 jitter design.
- `github.com/sony/gobreaker`: circuit breaker state와 half-open behavior.
- `golang.org/x/sync/semaphore`: bulkhead/concurrency limiter design.
- `golang.org/x/time/rate`: 이후 scope의 token-bucket rate limiter design.

## 결정

`resilience` package는 first-party implementation으로 만든다. 외부 Go library는 reference material이지 runtime dependency나
wrapper가 아니다. public API와 internal behavior는 bluetape-go가 소유해야 retry, timeout, circuit breaker, bulkhead,
HTTP integration 전반에서 composition, observability, deterministic test가 일관된다.
