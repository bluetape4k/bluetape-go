# 0.8.0 AWS Research

## Milestone

0.8.0 - AWS helper packages and Floci-backed examples.

## bluetape4k Evidence

- `bluetape4k-aws`: AWS Java/Kotlin SDK wrapper patterns and Spring/Ktor
  integrations.
- Examples cover S3, SQS, DynamoDB, and service integration patterns.
- Test strategy should align with Testcontainers and Floci.
- Floci is a MIT-licensed local AWS emulator that keeps LocalStack-compatible
  endpoint conventions such as port 4566, test credentials, and standard AWS
  SDK endpoint overrides.

## Go Direction

- Do not wrap AWS SDK for Go v2 without a clear repeated-service benefit.
- Start with a Floci Testcontainers fixture because it supports many future AWS
  examples without LocalStack Community auth-token or feature-gate coupling.
- Use a direct `floci/floci` container wrapper first; the official Go Floci
  Testcontainers module is still in progress.
- Prefer example-first packages for S3 and SQS.
- Evaluate DynamoDB helpers for conditional writes, optimistic locking, batch
  operations, and expression-builder pain points.

## Dependency Candidates

- `github.com/aws/aws-sdk-go-v2`: official AWS SDK for Go.
- `github.com/testcontainers/testcontainers-go`: Floci fixture runtime.
- `floci/floci`: local AWS emulator container image for integration tests.
- LocalStack may remain a compatibility reference, not the first fixture target.
