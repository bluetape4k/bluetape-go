# 0.8.0 AWS Research

## Milestone

0.8.0 - AWS helper package와 Floci-backed example.

## bluetape4k 근거

- `bluetape4k-aws`: AWS Java/Kotlin SDK wrapper pattern 및 Spring/Ktor integration.
- example은 S3, SQS, DynamoDB, service integration pattern을 덮는다.
- test strategy는 Testcontainers와 Floci에 맞춘다.
- Floci는 MIT-licensed local AWS emulator이며 port 4566, test credential, standard AWS SDK endpoint override 같은
  LocalStack-compatible convention을 유지한다.

## Go 방향

- 명확한 repeated-service benefit 없이 AWS SDK for Go v2를 감싸지 않는다.
- LocalStack Community auth-token 또는 feature-gate coupling 없이 많은 future AWS example을 지원할 수 있으므로 Floci
  Testcontainers fixture부터 시작한다.
- official Go Floci Testcontainers module은 아직 진행 중이므로 direct `floci/floci` container wrapper를 먼저 쓴다.
- S3와 SQS는 example-first package를 우선한다.
- DynamoDB helper는 conditional write, optimistic locking, batch operation, expression-builder friction을 평가한다.

## Dependency Candidates

- `github.com/aws/aws-sdk-go-v2`: official AWS SDK for Go.
- `github.com/testcontainers/testcontainers-go`: Floci fixture runtime.
- `floci/floci`: integration test용 local AWS emulator container image.
- LocalStack은 첫 fixture target이 아니라 compatibility reference로 남을 수 있다.
