# 0.11.0 AWS Research

## Milestone

0.11.0 - AWS helper packages and LocalStack examples.

## bluetape4k Evidence

- `bluetape4k-aws`: AWS Java/Kotlin SDK wrapper patterns and Spring/Ktor
  integrations.
- Examples cover S3, SQS, DynamoDB, and service integration patterns.
- Test strategy should align with Testcontainers and LocalStack.

## Go Direction

- Do not wrap AWS SDK for Go v2 without a clear repeated-service benefit.
- Start with LocalStack Testcontainers helpers because they support many future
  AWS examples.
- Prefer example-first packages for S3 and SQS.
- Evaluate DynamoDB helpers for conditional writes, optimistic locking, batch
  operations, and expression-builder pain points.

## Dependency Candidates

- `github.com/aws/aws-sdk-go-v2`: official AWS SDK for Go.
- `github.com/testcontainers/testcontainers-go`: LocalStack fixture runtime.
- LocalStack container image for integration tests.

## Decision

AWS support should be helper/example driven. The risk is duplicating the AWS SDK
instead of removing bluetape-specific repetition.
